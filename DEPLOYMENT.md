# Deployment — Render

## Status

## Deploy

1. Push this repository to your GitHub fork.
2. In Render, create a Blueprint from the repository. Set the Blueprint path to `06-lab-complete/render.yaml`.
3. Review the proposed `day14-agent` Web Service and `day14-redis` Key Value instance, both on the free plan in Singapore.
4. Apply the Blueprint. The Web Service builds from `06-lab-complete/Dockerfile`.
5. Copy the agent's public URL into `BASE` below. Obtain the generated `AGENT_API_KEY` from the service's Environment settings; do not paste it into this document or screenshots.
6. Run the four public checks below and capture the required deployment screenshots.

The Render agent key is generated separately from your local key. No Anthropic key is required: this lab runs the mock LLM.

## Environment variables

- `ENVIRONMENT=production`
- `AGENT_API_KEY`: generated by Render, never committed.
- `REDIS_URL`: populated from the Blueprint's Key Value internal connection string.
- `RATE_LIMIT_PER_MINUTE=10`
- `DAILY_BUDGET_USD=1.0`: simulated token-cost budget, resetting at midnight UTC.
- `PORT`: supplied by Render and used by the Docker startup command.

## Verification

Set `BASE` to the deployed URL, then enter the generated key without displaying it:

```bash
read -rsp 'Agent API key: ' AGENT_API_KEY; echo
export AGENT_API_KEY
curl -sS -o /dev/null -w '%{http_code}\n' "$BASE/health" # 200
curl -sS -o /dev/null -w '%{http_code}\n' "$BASE/ready"  # 200
curl -sS -o /dev/null -w '%{http_code}\n' -X POST "$BASE/ask" \
  -H 'Content-Type: application/json' -d '{"question":"Hello"}' # 401
curl -sS -o /dev/null -w '%{http_code}\n' -X POST "$BASE/ask" \
  -H 'Content-Type: application/json' -H "X-API-Key: $AGENT_API_KEY" \
  -d '{"question":"Hello"}' # 200
```

## Lab limitations

- Free Render Key Value has no persistence across datastore restarts. State survives agent restarts as long as Redis remains running. Local Compose uses an AOF-enabled Redis volume.
- Costs are estimates based on mock word counts, not provider billing. Budget checks happen before each LLM call; already admitted concurrent calls can exceed the budget before subsequent calls are blocked.
- The Dockerfile uses the public ECR Docker-library Python mirror because Docker Hub returned HTTP 429 during verification.
